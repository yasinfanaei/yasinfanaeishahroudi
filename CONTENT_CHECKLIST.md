# Academic Pro 2 Content Checklist

Before publishing content from Pages CMS:

- Use only information intended for a public academic website.
- Never store government IDs, birth date, marital status, passwords or private contact details.
- For public phone/email/WhatsApp, add them intentionally through Profile Contacts and choose visibility locations.
- Keep page IDs stable after publication.
- Use lowercase ASCII kebab-case page slugs.
- Pair translations with the same `translation_key`.
- Keep drafts as `draft` until ready.
- Give meaningful public images alt text.
- Do not invent DOI, URLs, volume, issue, page range, official English titles, data/code/replication links or publication status.
- Keep old published page paths in `redirect_from` when changing a slug.
- Use Page references in navigation instead of manually copying internal URLs.
- Use HTTPS for external navigation links.
- Prefer a built-in theme preset; if using Custom, run validation after color changes.
- Run Pages CMS **Validate site** after substantial structural changes.
